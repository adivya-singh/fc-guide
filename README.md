# The FC Guide

A responsive FC Mobile player explorer and squad-building application built
with semantic HTML, modern CSS and vanilla JavaScript.

## Features

- Search players by name, nickname, nation or position
- Filter by player category and sort by rating or name
- Compare two players side by side
- Save favourite players with `localStorage`
- Build and persist an eleven-player squad
- Browse dedicated player profile pages
- Responsive layout with accessible controls and reduced-motion support
- Autoplaying, user-controlled testimonial carousel
- Optimized local image assets for faster page loads

## Run locally

No installation or build step is required. Open `index.html` in a browser, or
serve the directory with a local development server.

For example, with VS Code you can use the Live Server extension.

## Project structure

```text
.
├── index.html       # Main application
├── style.css        # Responsive application and profile styles
├── script.js        # Player data and interactive features
├── players/         # Individual player profiles
└── images           # Player and interface artwork
```
